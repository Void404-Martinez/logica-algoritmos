## 📝 Exercício 5

### 📌 Enunciado

> Faça um programa que leia duas notas de um aluno e mostre a média entre elas.

### 💻 Código

```text
INICIO
    ESCREVA("Digite a primeira nota: ")
    LEIA nota1

    ESCREVA("Digite a segunda nota: ")
    LEIA nota2

    media = (nota1 + nota2) / 2

    ESCREVA("A média entre " ,nota1, " e " ,nota2, " é igual a " ,media, ".")
FIM
```

### 📖 Explicação

Este algoritmo utiliza comandos de entrada e saída para ler duas notas de um aluno, calcular a média aritmética entre elas e exibir o resultado na tela.

### 🔎 Fluxo do algoritmo

* `INICIO` → inicia o algoritmo
* `ESCREVA(...)` → solicita a primeira nota do aluno
* `LEIA nota1` → lê a primeira nota informada
* `ESCREVA(...)` → solicita a segunda nota do aluno
* `LEIA nota2` → lê a segunda nota informada
* `media = (nota1 + nota2) / 2` → calcula a média aritmética das duas notas
* `ESCREVA(...)` → exibe a média calculada na tela
* `FIM` → finaliza o algoritmo
