# 📝 Exercício 2

## 📌 Enunciado

> Faça um programa que leia o nome de uma pessoa e mostre uma mensagem de boas-vindas.

## 💻 Código

```text
INICIO
    ESCREVA("Digite seu nome: ")
    LEIA nome

    ESCREVA("Olá", nome ,", é um prazer te conhecer!")
FIM
```

## 📖 Explicação

Este algoritmo utiliza comandos de entrada e saída para interagir com o usuário, lendo um nome e exibindo uma mensagem personalizada.

### 🔎 Fluxo do algoritmo

* `INICIO` → inicia o algoritmo
* `ESCREVA(...)` → exibe mensagens na tela
* `LEIA nome` → lê o nome digitado pelo usuário
* `ESCREVA(...)` → mostra a mensagem de boas-vindas
* `FIM` → finaliza o algoritmo
