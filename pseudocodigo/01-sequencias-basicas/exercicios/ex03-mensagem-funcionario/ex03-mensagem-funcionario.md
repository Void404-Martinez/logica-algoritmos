# 📝 Exercício 3

## 📌 Enunciado

> Faça um programa que leia o nome e o salário de um funcionário e mostre uma mensagem com essas informações.

## 💻 Código

```text id="n7v3qx"
INICIO
    ESCREVA("Digite seu nome: ")
    LEIA nome

    ESCREVA("Digite seu salário: ")
    LEIA salario

    ESCREVA("O funcionário", nome ,", tem um salário de", salario ,"em junho")
FIM
```

## 📖 Explicação

Este algoritmo utiliza comandos de entrada e saída para interagir com o usuário, lendo informações e exibindo uma mensagem personalizada na tela.

### 🔎 Fluxo do algoritmo

* `INICIO` → inicia o algoritmo
* `ESCREVA(...)` → exibe mensagens na tela
* `LEIA nome` → lê o nome do funcionário
* `LEIA salario` → lê o salário informado
* `ESCREVA(...)` → mostra a mensagem com os dados do funcionário
* `FIM` → finaliza o algoritmo
