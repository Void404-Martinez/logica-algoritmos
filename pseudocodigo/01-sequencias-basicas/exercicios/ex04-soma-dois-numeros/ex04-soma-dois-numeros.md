## 📝 Exercício 1

### 📌 Enunciado

> Faça um programa que leia dois números inteiros e mostre o somatório entre eles.

### 💻 Código

```text
INICIO
    ESCREVA("Digite um número: ")
    LEIA num1

    ESCREVA("Digite um número: ")
    LEIA num2

    soma = num1 + num2

    ESCREVA("A soma entre ", num1, " e ", num2, " é igual a ", soma, ".")
FIM
```

### 📖 Explicação

Este algoritmo utiliza comandos de entrada e saída para interagir com o usuário, lendo dois números inteiros e calculando a soma entre eles.

### 🔎 Fluxo do algoritmo

* `INICIO` → inicia o algoritmo
* `ESCREVA(...)` → solicita que o usuário digite um número
* `LEIA num1` → lê o primeiro número informado
* `ESCREVA(...)` → solicita que o usuário digite o segundo número
* `LEIA num2` → lê o segundo número informado
* `soma = num1 + num2` → calcula a soma dos dois números
* `ESCREVA(...)` → exibe o resultado da soma na tela
* `FIM` → finaliza o algoritmo
